# Input Method можно выбирать; по умолчанию — PostMessage-клик по Game Macro

LU4 запущен от администратора и защищён Active Anticheat, поэтому приложение тоже работает от администратора (иначе UIPI блокирует любой ввод). Пробы 2026-10-04 (`probe/`) показали: ни один способ эмуляции клавиатуры (SendInput VK и scancode, keybd_event, PostMessage/SendMessage WM_KEYDOWN) не доходит до игровых действий. Клик мышью по ячейке с умением тоже не срабатывает. Срабатывает **клик мышью по Game Macro** (ячейка панели или окно Macro): SendInput в активном окне и **PostMessage WM_LBUTTONDOWN/UP в фоновое окно** (клиент в оконном режиме и не свёрнут). Умение вызывается через макрос (`/useskill`). Поэтому Input Method в приложении можно выбирать из всех известных вариантов, а по умолчанию стоит PostMessage-клик по Shortcut Slot с Game Macro. Это единственный способ, который работает в фоне, не двигает курсор и не забирает фокус.

## Consequences

- Каждое действие, которое должен выполнять кликер, пользователь оформляет как Game Macro в Shortcut Slot.
- Клиент должен быть в оконном режиме и не свёрнут. Полноэкранный клиент в фоне не отрисовывается, свёрнутый не принимает клики.
- Способы клавиатурного ввода остаются в списке, но для LU4 известно, что они не работают. Для них нужен драйвер (Interception) или аппаратный HID; этот вариант отложен.
