# MyClicker

Автокликер для Windows: от имени пользователя нажимает клавиши клавиатуры и кнопки мыши в окне выбранного игрового клиента.

## Language

**Client (Клиент)**:
Один запущенный экземпляр игры, к которому привязан один персонаж. Узнаётся по заголовку окна `LU4 - <имя персонажа>`.
_Avoid_: окно, игра, приложение

**Key Press (Нажатие клавиши)**:
Нажатие и отпускание одной клавиши клавиатуры, доставленное в **Client**.
_Avoid_: клик клавиши

**Mouse Click (Клик мыши)**:
Нажатие и отпускание одной кнопки мыши в точке внутри **Client**.
_Avoid_: клик (без уточнения)

**Input Method (Способ ввода)**:
Механизм, которым **Key Press** или **Mouse Click** доставляется в **Client** (например, оконное сообщение, программная инъекция, драйвер, аппаратное устройство).
_Avoid_: способ эмуляции, бэкенд

**Background Input (Фоновый ввод)**:
**Input Method**, которому не нужно, чтобы **Client** был активным окном.
_Avoid_: ввод без фокуса

**Shortcut Slot (Ячейка панели)**:
Ячейка панели быстрого доступа внутри **Client**, в которую положено умение, предмет или **Game Macro**.
_Avoid_: хоткей, кнопка

**Game Macro (Игровой макрос)**:
Макрос, созданный в самой игре (окно Macro): набор игровых команд, например `/unstuck`.
_Avoid_: макрос (без уточнения), скрипт

**Target (Цель)**:
Куда и как доставлять ввод: **Client**, точка внутри него (для **Mouse Click**) или клавиша (для **Key Press**), и **Input Method**.
_Avoid_: координаты, точка

**Slot Fingerprint (Отпечаток ячейки)**:
Снимок области вокруг точки **Target**, сделанный при захвате. Перед кликом его сверяют с текущим видом, чтобы не кликнуть вслепую.
_Avoid_: скриншот, шаблон

**Action (Действие)**:
**Target** плюс расписание: повторять каждые N секунд со случайным разбросом.
_Avoid_: задача, таймер

**Profile (Профиль)**:
Именованный набор **Actions** для одного **Client**. Имя задаёт пользователь. **Client** находится по заголовку окна (точному или по шаблону).
_Avoid_: конфиг, настройки

**Mini Panel (Мини-панель)**:
Маленькое окно приложения поверх всех окон: «Старт/Стоп», «Открыть приложение», статус.
_Avoid_: оверлей, виджет

## Relationships

- Одновременно может быть запущено несколько **Clients**; каждое **Key Press** / **Mouse Click** адресовано ровно одному **Client**
- Не каждый **Input Method** умеет **Background Input**
- У **Profile** много **Actions**; все **Actions** всех **Clients** идут одновременно и независимо
- **Action** с **Mouse Click** ставится на паузу, если **Slot Fingerprint** не совпал или **Client** свёрнут или закрыт
- Игровое действие запускается **Mouse Click** по **Shortcut Slot** с **Game Macro**; **Key Press** до игровых действий не доходит

## Flagged ambiguities

- Слово «клик» использовалось и для клавиш, и для мыши. Решение: **Key Press** для клавиатуры, **Mouse Click** для мыши.
