# MyClicker

Автокликер для Windows. Кликает мышью и нажимает клавиши в окнах игр и программ, в том числе **в фоне**: окно не нужно делать активным, курсор не двигается. Можно управлять несколькими клиентами одновременно.

Первая цель — LU4. Что там работает, а что нет: [docs/research/lu4-input-methods.md](docs/research/lu4-input-methods.md).

## Запуск

Нужен Python 3.12+ (Windows). Сторонних библиотек нет.

```
python run.py
```

Программа запросит права администратора: игры, запущенные от администратора, принимают ввод только от таких же процессов. Настройки и профили сохраняются в `data/` рядом с программой, так что папку можно переносить целиком.

## Как пользоваться (LU4)

1. В игре положите нужное действие в **игровой макрос**, а макрос — в ячейку панели. Например, `/useskill …`.
2. В MyClicker нажмите «Новый» и создайте профиль.
3. Наведите мышь на ячейку с макросом и нажмите **Ctrl+Alt+C**. Добавится клик, профиль привяжется к этому окну, программа запомнит отпечаток ячейки.
4. Задайте интервал (двойной щелчок по строке) и нажмите **Ctrl+Alt+S** (Старт/Стоп). То же самое есть в мини-панели в левом верхнем углу экрана.

Окно игры должно быть в **оконном режиме** и не свёрнуто. Клик не отправляется, если окно свёрнуто, закрыто или ячейка выглядит не так, как при захвате; когда всё вернётся, кликер продолжит сам.

Горячие клавиши (меняются на вкладке «Настройки»):

| Клавиши | Что делают |
|---|---|
| Ctrl+Alt+S | Старт/Стоп |
| Ctrl+Alt+C | добавить клик в точке под курсором |
| Ctrl+Alt+A | привязать выбранный профиль к окну под курсором |

## Способы ввода

На вкладке «Способы ввода» перечислены все реализованные способы: PostMessage, SendMessage, SendInput, mouse_event, keybd_event, WM_CHAR, драйвер Interception, Arduino HID (пока заглушка). Для каждого показано, доступен ли он, и что о нём известно для выбранной программы. Свои результаты можно отмечать: они хранятся в `data/compatibility.json`.

Для Interception нужен установленный драйвер и `interception.dll` рядом с программой (или распакованный пакет `Interception/`).

## Разработка

```
python -m unittest discover -s tests -t .
```

- `myclicker/domain` — модель, расписание, движок, отпечатки, совместимость. Без Windows, покрыто тестами.
- `myclicker/persistence` — портативное хранилище (JSON + PNG).
- `myclicker/platform_win` — WinAPI: окна, снимки, все реализации способов ввода, горячие клавиши, права администратора.
- `myclicker/app` — контроллер, через который работает интерфейс.
- `myclicker/ui` — tkinter.
- `probe/` — скрипты исследования (результаты в `probe/results/` в git не попадают).
